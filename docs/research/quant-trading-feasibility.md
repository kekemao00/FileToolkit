# 个人自动化 / 量化交易工具可行性调研报告

> **一句话结论**：对个人开发者而言，"做一个能稳定赚钱的交易机器人"的可行性很低（学术证据：97% 的日内交易者亏损），但"做一个让自己少犯错、低成本执行有结构性优势的策略的自动化系统"是可行的，而且是唯一值得做的方向。本报告给出三条按风险分层的落地路线，并对每个赛道做了合法性、门槛、预期边际的打分。

## 0. 执行摘要

### 0.1 五个核心判断

| # | 判断 | 依据 |
|---|------|------|
| 1 | **"自动化"比"量化"更值得投入。** 个人最大的敌人不是没有 alpha，而是情绪、手滑、漏单、不守纪律。一个可靠的执行与风控系统本身就是正收益。 | 巴西 / 台湾 / 美国三项学术研究一致显示绝大多数主动交易者亏损，且亏损主因是过度交易与成本 |
| 2 | **预测市场（Polymarket / Kalshi）对中国大陆居民是"只能研究、不能交易"。** 两家平台均在服务条款中明确限制中国大陆，Polymarket 从 2026-05-27 起严打 VPN；境内还有刑事风险。 | 见 §3.5、§5.2 |
| 3 | **国内商品期货是中国个人做程序化交易最成熟、最合法的路线。** 开户无资金门槛、CTP 接口免费、vn.py 原生支持、T+0 双向。2025-10-09 起需先报备再交易。 | 见 §3.1、§5.4 |
| 4 | **加密市场的边际最肥（资金费率套利 3–12% 年化 / 长尾 20–60%+），但大陆居民面临法律灰区 + 外汇监测。** 只有具备境外身份 / 香港账户时才建议真金白银参与。 | 见 §3.3、§3.4、§5.1 |
| 5 | **LLM 的正确位置是研究助手，不是交易决策者。** 多项 2026 年论文指出 LLM 回测存在严重的"信息泄露 / 前视偏差"，TradingAgents 官方明确建议不要用真钱。 | 见 §3.8、§6.5 |

### 0.2 推荐路线（详见 §8）

| 方案 | 定位 | 市场 | 首期资金 | 技术栈 | 12 周目标 |
|------|------|------|---------|--------|-----------|
| **A · 稳健（推荐首选）** | 合法、低门槛、能验证工程能力 | 国内商品期货 + 可转债 / ETF | 2–5 万 CNY | vn.py + CTP / QMT | 跑通"数据→回测→模拟盘→实盘小仓位"全链路 |
| **B · 进取** | 追求真实边际 | 加密永续资金费率套利、Hyperliquid 做市 | 1–3 万 USDT（需合规身份） | Hummingbot / NautilusTrader + ccxt | 在模拟 + 小仓位上验证净 APR ≥ 8% |

### 0.3 不建议做的事

- 不要从"消息买卖 / 新闻情绪 + LLM 全自动下单"起步：噪音最大、最难验证、最容易被回测欺骗。
- 不要做需要速度的事（HFT、抢跑、狙击）：个人在延迟、费率、信息上三重劣势。
- 不要用 VPN 绕过 Polymarket / Kalshi / 币安的地域限制：账户变 close-only、资金冻结、且境内有刑事风险。

## 1. 调研前提与方法

### 1.1 你的约束（从需求反推）

- 个人开发者，有 Python 工程能力（已有 Flet 桌面应用项目）。
- 对市场形式无偏好：股票、加密、预测市场、消息驱动均可。
- 目标是"自动化或量化的工具"，关注**可行性**而不是立刻盈利。
- 默认所在地：中国大陆（WSL 开发环境、中文语境）。合规章节以此为基准，若你有境外身份，请按 §5 的分支重新评估。

### 1.2 方法

- 2026-10 联网调研 20+ 轮检索，覆盖平台官方文档、CFTC 备案、证监会 / 交易所公告、arXiv 论文、主流媒体与社区。
- 对每条关键事实标注**证据等级**：
  - 🟢 一手来源（官方文档 / 监管文件 / 同行评审论文）
  - 🟡 二手来源（主流媒体、未经同行评审的预印本、多家博客交叉印证）
  - 🔴 弱来源（单一博客、营销页、无法交叉验证）
- 所有数字均可能过时，报告末尾附参考链接，实施前请复核。

### 1.3 评估维度

每个赛道从七个维度打分（1–5）：**合法性、准入门槛、数据可得性、预期边际、策略容量、技术复杂度、资金要求**。详见 §7。

## 2. 一个残酷的基线：个人交易的真实胜率

在设计任何工具之前，先校准期望。

| 研究 | 样本 | 结论 | 证据 |
|------|------|------|------|
| Chague, De-Losso & Giovannetti（巴西，2013–2015） | 坚持日内交易 ≥300 天的个人 | **97% 亏损**，仅 0.4% 收入超过银行柜员；没有"越练越好"的证据 | 🟢 |
| Barber, Lee, Liu & Odean（台湾，1992–2006） | 全市场日内交易者 | 扣除费用后 **<1%** 能持续获得正超额收益 | 🟢 |
| Barber & Odean（美国折扣券商） | 最活跃交易者 | 年化 11.4%，同期市场 17.9%：交易越多越差 | 🟢 |
| Saguillo 等（IMDEA，Polymarket 2024–2025） | 8600 万笔下注 | 约 **$40M** 被套利者抽走；社区统计前 20 盈利钱包中 14 个是机器人 | 🟡（预印本） |
| Thorsten Meyer 分析（Polymarket 机器人用户） | 公开钱包 | 仅 **0.51%** 钱包盈利超 $1,000，多数零售机器人扣费后亏损 | 🔴 |

**对工具设计的启示：**

1. 亏损主因是**成本 + 过度交易 + 行为偏差**，不是"没有好模型"。所以系统第一优先级是：限制交易频率、压低成本、强制风控。
2. 已被广泛报道的异象（如美股隔夜效应）**毛收益存在，但扣除费用后对小资金不成立**（QuantConnect 回测显示 20 年佣金吃掉约 25% 本金）。
3. 个人真正的结构性优势只有三个：**小资金可以进大资金进不去的角落**（长尾市场、小众合约）、**不需要规模**（年化 10% 对个人有意义，对基金没意义）、**运营灵活**（可以随时停、随时改）。

## 3. 赛道全景：十类可选市场逐一拆解

### 3.1 国内商品 / 金融期货（CTP）

| 项目 | 现状 | 证据 |
|------|------|------|
| 准入 | 商品期货开户无资金门槛；金融期货（股指 / 国债）需 50 万验资 + 测试 | 🟢 |
| 接口 | CTP 为行业标准，期货公司免费提供；SimNow 提供免费模拟环境 | 🟢 |
| 框架 | vn.py（VeighNa，46k⭐，MIT）原生支持 CTP / CTP Mini / Femas / Esunny 等十余个国内网关 | 🟢 |
| 交易机制 | T+0、双向、杠杆 5–10 倍、夜盘 | 🟢 |
| 监管 | 《期货市场程序化交易管理规定（试行）》2025-10-09 施行：**程序化交易前须向期货公司报告，收到确认后方可交易**；五大交易所同步发布实施办法；高频认定标准由交易所制定 | 🟢 |
| 费用 | 手续费万分之几到每手几元，部分品种日内平今免费或加收 | 🟢 |

**适合策略**：趋势跟踪（CTA）、跨期 / 跨品种价差、日内突破、波动率收缩。
**判断**：✅ 中国个人程序化交易的"正门"。缺点是杠杆带来爆仓风险，需严格仓位管理；CTA 策略在 2024–2026 的拥挤度上升。

### 3.2 A 股 / 可转债 / ETF（QMT · PTrade）

| 项目 | 现状 | 证据 |
|------|------|------|
| 准入 | QMT / PTrade 量化权限门槛普遍降至 **10 万元**（国金等），部分券商仍要求 50 万–500 万；需 C3/C4 风测、半年交易经验，且通常只能通过客户经理渠道开通 | 🟡 |
| 接口 | QMT（本地 Python / VBA，含 MiniQMT 轻量版）、PTrade（云端）；正规渠道不收软件费 | 🟡 |
| 交易机制 | 股票 T+1；**可转债 T+0**、无印花税；ETF T+1（跨境 / 债券 / 黄金等部分 T+0） | 🟢 |
| 监管 | 《程序化交易管理实施细则》2025-07-07 施行：高频认定线 **每秒申报+撤单 ≥300 笔 或 全日 ≥20,000 笔**；四类异常交易（瞬时申报速率异常、频繁瞬时撤单、频繁拉抬打压、短时间大额成交）；试运行期间触发者主要是机构 | 🟢 |
| 数据 | AkShare（免费）、Tushare（积分制）、券商行情；QMT 自带行情 | 🟢 |

**适合策略**：可转债双低轮动、ETF 网格 / 折溢价、低频多因子、定投增强。
**判断**：✅ 合法、数据丰富、社区大。边际薄（可转债轮动近年拥挤），但作为"自动化执行 + 纪律"工具价值高。

### 3.3 港美股（IBKR · 富途 · 长桥 · 老虎 · Alpaca）

| 券商 | API 特点 | 费用 / 门槛 | 证据 |
|------|---------|------------|------|
| Interactive Brokers | 最全（170 市场、股 / 期 / 权 / 债 / 汇）；TWS Socket + 异步事件模型，上手需数天；NautilusTrader / vn.py 均有适配器 | 无最低资金；行情订阅另付 | 🟢 |
| 富途 OpenAPI | FutuOpenD 网关，接口免费不限次；港股 LV1 / 美股 LV1-2 行情入金达标后免费 | 港股账户约 1 万港币起 | 🟡 |
| 长桥 OpenAPI | 云原生、多语言 SDK（Python / Rust / Go / Node / Java），免费；港股平台费阶梯 | 以官网为准 | 🟡 |
| 老虎 OpenAPI | 官方文档：API 交易无附加费；**行情权限需单独购买，同一时间仅一台设备** | 以官网为准 | 🟢 |
| Alpaca | API-first、无门槛、无限纸面交易；主要美股 / ETF / 期权 / 加密；支持 30+ 国家 | 需核对中国大陆是否在列 | 🟡 |

**税务红线（2026 新变化）**：税务总局 2026-04 重申境内外所得均须纳税，6/30 前汇算；2026 年 1–5 月追缴境外所得税款约 **130 亿元**；多名港美股投资者收到 2022–2024 年补税通知。股票差价与股息均按 **20%**，年度盈亏可抵、亏损不可跨年结转。详见 §5.3。

**适合策略**：低频因子 / ETF 轮动、期权卖方（备兑 / 现金担保 put）、事件驱动（财报、指数纳入）。
**判断**：✅ 合法（需申报纳税）。美股市场效率高，个人边际主要来自**期权保费 + 纪律**而非预测。

### 3.4 加密货币 · 中心化交易所（币安 / OKX / Bybit）

| 项目 | 现状 | 证据 |
|------|------|------|
| 法律（大陆） | 2021 年"9·24 通知"：境外交易所向境内居民提供服务属非法金融活动；个人持有处灰色地带，经营性行为受打击。2024-12 外汇局将虚拟货币跨境活动纳入银行外汇风险监测 | 🟢 |
| 法律（香港） | SFC VATP 持牌制（HashKey、OSL、HKVAX 等）；散户仅限大市值币（BTC / ETH 等）；**需香港银行账户出入金**，内地居民基本无法开户 | 🟡 |
| 接口 | ccxt 统一封装 100+ 交易所；freqtrade（55.8k⭐）支持 Binance / Bybit / OKX / Gate / Bitget / Kraken / Hyperliquid 现货与合约 | 🟢 |
| 边际 | 资金费率套利：主流币 **3–12% 净 APR**，长尾 20–60%+（NeuralArb 2026-04）；Hyperliquid BTC 资金费率 2023–2026 平均高于币安约 7 个百分点，90 天窗口 95% 为正（BitMEX 报告） | 🟡 |
| 风险 | 费率反转可抹掉基差；Hyperliquid 滑点 $1M ≈0.28%、$5M ≈0.85%；交易所风险（挤兑、下架） | 🟡 |

**适合策略**：资金费率 / 基差套利、跨所套利、网格、做市（Hummingbot）。
**判断**：⚠️ 边际最好、工具最成熟，但大陆居民合规风险真实存在。**只建议在有境外身份 / 香港合规通道时投入真金**；否则仅做模拟与研究。

### 3.5 加密货币 · 链上 / DEX（Hyperliquid 等）

| 项目 | 现状 | 证据 |
|------|------|------|
| 平台 | Hyperliquid 为链上 CLOB 永续 DEX；官方 Python SDK + 社区 SDK；公共 RPC 限 100 req/min（2025-08 起） | 🟡 |
| 生态 | Builder Codes：第三方应用可抽成（永续最高 0.1%、现货 1%），已向开发者支付 >$65M；HLP 金库允许散户向做市策略出资 | 🟡 |
| 框架 | Hummingbot（20.6k⭐，Apache-2.0）、NautilusTrader（30.6k⭐，Rust 核心）、freqtrade 均已接入 Hyperliquid | 🟢 |
| 优势 | 无 KYC（但有地域 IP 限制）、套利资本较 CEX 更薄，极端资金费率持续更久 | 🟡 |

**适合策略**：CEX–DEX 资金费率套利、HLP 被动做市、长尾币做市。
**判断**：⚠️ 同 3.4，技术上最适合个人（API 友好、无最低门槛），合规上同样处于灰区。另有一个**合法的"旁路"**：做工具而非做交易——基于 Builder Codes 开发前端 / 机器人向他人收费（但对大陆居民同样涉及向境内推广虚拟货币服务的风险）。

### 3.6 预测市场（Polymarket · Kalshi）

**判断**：❌ **对大陆居民：不可交易，可研究。** 预测市场是 2026 年最有意思的新市场，但两大平台均明确排除中国大陆，且境内存在"开设赌场罪 / 帮信罪"的刑事风险（律师解读，非司法认定）。若你有合规身份，预测市场的个人机会在于**做市 + 组合套利**，而非预测本身；注意 Taker 延迟与 UMA 尾部风险。

### 3.7 体育交易所（Betfair）

- Betfair Exchange API（JSON-RPC / REST + Stream API）成熟 20 年，是"预测市场"的鼻祖；NautilusTrader 有稳定适配器。
- 地域限制：美国不可用；中国在其历史受限名单中，现行名单需核对。
- **判断**：❌ 同预测市场，大陆居民不可用；且涉博彩，法律风险更高。仅作思维参照。

### 3.8 消息 / 情绪驱动（LLM Agent）

| 项目 | 现状 | 证据 |
|------|------|------|

- **判断**：❌ 不推荐。

### 3.10 延伸思维：非金融的"市场"

用户提到"任何形式"，这里列出几个常被忽视、但确实有人用程序化方式获利的市场。它们不属于证券监管，但各有平台规则与税务问题。

| 市场 | 机制 | 工具可行性 | 风险 |
|------|------|-----------|------|
| Steam 饰品 / 卡牌 | 社区市场 + 第三方平台（BUFF、悠悠有品）价差、汇率差 | API 半开放，国内社区成熟 | 平台封号、政策（未成年、博彩联想）、流动性 |
| 球鞋 / 潮玩 / 集换卡 | StockX / 得物 价差与发售套利 | 爬虫 + 自动下单 | 反爬、物流、假货 |

### 4.2 一个判断公式

每个候选策略在进入回测之前先回答：

1. **谁在亏给我？** 说不出对手盘就没有边际。
2. **为什么对手盘不自己做？** 规模限制 / 合规限制 / 不在乎这点钱 → 结构性；只是没发现 → 很快消失。
3. **扣除费用、滑点、冲击后还剩多少？** 用最悲观的成本假设。
4. **最坏情况损失多少？** 尾部风险能否被仓位 / 对冲限制。
5. **这个边际在我所在的法域能合法获取吗？**

## 5. 合规与税务：中国大陆居民视角

> 本节为公开信息整理，不构成法律 / 税务意见。涉及真实资金前请咨询持牌律师与税务师。

### 5.1 虚拟货币

| 行为 | 状态 | 依据 |
|------|------|------|
| 个人持有 | 灰色（不被保护，也未明令禁止） | 2021 年"9·24 通知" |
| 境外交易所向境内居民提供服务 | **非法金融活动** | 同上 |
| 经营性 / 推广 / 为他人提供交易服务 | 高风险（非法经营、帮信、洗钱） | 多起司法案例 |
| 跨境资金 | 纳入银行外汇风险交易报告监测（2024-12） | 外汇局《银行外汇风险交易报告管理办法（试行）》 |
| 香港持牌平台 | 合法，但散户限大市值币，需香港银行账户 | SFC VATP 制度 |

**实操结论**：没有境外身份 / 香港银行账户时，加密路线只做模拟与研究；有合规通道时，优先选择受监管平台，并保留完整的出入金记录。

### 5.2 预测市场

- Polymarket 全球站：服务条款 2.1.4 禁止 VPN；中国大陆在限制下单名单；2026-05-27 起加强风控。
- Polymarket 中文版（2026-02）上线反而被解读为"面向境内"信号，引发监管关注。
- Kalshi：会员协议 55 个受限辖区含中国，违规可撤销 API。
- 境内刑事风险：律师分析认为组织、推广、提供技术接入可能触及**开设赌场罪、帮助信息网络犯罪活动罪**；Gate.io 宣称"国内免 VPN 接入 Polymarket"被评论认为触碰红线。
- **实操结论**：公开数据（Gamma / Data / CLOB 读接口免费无需认证）可用于研究；**不要下单**。

### 5.3 境外所得税务（港美股 / 加密）

| 项目 | 规则 | 证据 |
|------|------|------|
| 征税范围 | 居民个人境内外所得均须申报 | 🟢 税务总局 2026-04 发布会 |
| 税率 | 财产转让所得（差价）20%；利息股息红利 20% | 🟡 |
| 盈亏 | 同年可抵，亏损不可跨年 | 🟡 |
| 抵免 | 境外已预扣税可按规定抵免 | 🟡 |

| 执法 | 2026 年 1–5 月追缴约 130 亿元；流程为提示提醒 → 督促整改 → 约谈 → 稽查 → 曝光 | 🟡 |
| 外汇 | 个人年度购汇额度 5 万美元，且不得用于境外证券投资（历史口径） | 🟢 |

**实操结论**：港美股路线合法但**必须纳税**；系统设计时就应内置交易流水导出与年度盈亏汇总功能。

### 5.4 国内程序化交易报备

| 市场 | 规则 | 生效 |

## 6. 技术架构与选型

### 6.1 参考架构

```
┌──────────────────────────────────────────────────────────────────┐
│                        研究层（离线，可用 LLM）                       │
│  数据采集 → 清洗/对齐 → 特征/因子 → 回测（含成本模型） → 报告        │
│  工具：AkShare / Tushare / ccxt / Databento · vectorbt / backtrader  │
│        · Jupyter · Claude Code（写代码、读文献、找 bug）               │
└───────────────┬──────────────────────────────────────────────────┘
                │ 策略参数 / 模型文件（版本化）
┌───────────────▼──────────────────────────────────────────────────┐
│                        执行层（在线，确定性，无 LLM）                  │
│  行情网关 ─▶ 事件引擎 ─▶ 策略 ─▶ 风控闸门 ─▶ 订单管理 ─▶ 交易网关     │
│   (WS/CTP)   (vn.py /    (无状态)  (仓位/亏损/   (幂等/重试)  (券商/交易所)│
│              Nautilus)            频率/黑名单)                        │
└───────────────┬──────────────────────────────────────────────────┘
                │ 事件流
┌───────────────▼──────────────────────────────────────────────────┐
│                        运维层                                       │
│  持久化(SQLite/Postgres) · 监控(Grafana) · 告警(Telegram/飞书)        │
│  · 一键急停 · 对账 · 税务流水导出 · 日志审计                           │
└──────────────────────────────────────────────────────────────────┘
```

**三条设计原则**

1. **研究与执行物理分离**：LLM、Jupyter、网络爬虫只存在于研究层；执行层只跑经过版本化的确定性代码。
2. **风控闸门是独立模块**，策略无权绕过：单笔上限、日亏损上限、最大持仓、下单频率、合约白名单、"心跳丢失即平仓"。
3. **一切可回放**：所有行情与订单事件落盘，任何实盘异常都能在本地重放复现。

### 6.5 LLM 在管线中的正确位置

| ✅ 推荐 | ❌ 不推荐 |

## 8. 推荐路线图：三个方案

### 方案 A · 稳健（首选）：国内期货 + 可转债，vn.py 全链路

**目标**：12 周内跑通"数据 → 回测 → 模拟盘 → 小仓位实盘"闭环，并沉淀一个可复用的个人交易基础设施。

| 周 | 里程碑 | 交付物 |
|----|--------|--------|
| 1–2 | 开户（期货 + 10 万门槛券商 QMT）；完成程序化报备；搭 vn.py + SimNow | 可连接模拟盘的工程骨架 |
| 3–4 | 数据层：AkShare / 交易所日线 + CTP 分钟线落库；成本模型（手续费、滑点、冲击） | 本地 DuckDB 数据仓库 |
| 5–6 | 研究层：vectorbt 回测 2 个结构性策略（可转债双低、跨期价差）+ 1 个 CTA | 回测报告（含最悲观成本） |
| 7–8 | 执行层：策略移植到 vn.py；风控闸门；Telegram 告警；一键急停 | 模拟盘连续运行 2 周 |
| 9–10 | 对账与回放：事件落盘、异常重放；税务 / 流水导出 | 运维手册 |
| 11–12 | 实盘：总资金 ≤5%，单策略 ≤2% 风险预算；每周复盘 | 实盘 4 周记录 |

**预算**：首期资金 2–5 万 CNY；基础设施 ≤¥300/月。
**成功标准**：不是盈利，而是**零人工干预运行 4 周、无漏单、无风控穿透**。

### 方案 B · 进取：加密资金费率套利 / 做市（需合规身份）

**前提**：持有境外身份或香港合规账户；否则本方案只在模拟盘执行。

| 周 | 里程碑 |

| 5–6 | Hummingbot 跨所对冲控制器 / freqtrade 合约策略，Testnet 跑通 |
| 7–8 | 实盘 ≤$2,000；监控：基差、保证金率、资金费率预测、交易所状态 |

**红线**：单边敞口 >2% 自动平仓；任一交易所提币异常立即撤出。

## 9. 风险清单与踩坑预警

### 9.1 市场与策略

- **回测幸存者偏差**：可转债、币种都有退市 / 下架，务必用含已退市样本的数据。
- **成本低估**：期货平今、加密 Taker、滑点随规模非线性增长（Hyperliquid $5M ≈0.85%）。
- **拥挤**：双低轮动、CTA、费率套利均在 2024–2026 显著拥挤，预期收益打折。
- **尾部**：期权卖方、做市、费率套利的"稳定小赚"都伴随偶发大亏，必须限仓 / 对冲。
- **解析 / 规则风险**：预测市场 UMA 争议、交易所临时改规则（Polymarket 2026-03 费率 V2、CLOB V2）。

### 9.2 工程

- **幂等与重试**：网络抖动导致重复下单是最常见的实盘事故。
- **时钟与时区**：A 股 / 美股 / 加密三套交易日历；CTP 夜盘跨日。
- **心跳丢失**：行情断流时策略不应继续按旧价决策；默认行为应是"停"。
- **密钥管理**：API Key 只读 / 交易分离，禁止提币权限，使用 IP 白名单。
- **前视偏差**：所有特征必须是"当时可知"，LLM 文本尤其危险。

### 9.3 合规与资金

- 不用 VPN 绕限制；不在境内为他人提供交易服务；不替他人代操作。
- 港美股收益主动申报，保留流水。
- 期货 / 股票程序化先报备。
- 加密出入金走合规渠道，避免 OTC 对手盘涉案导致银行卡冻结。

### 9.4 心理

- 实盘前写下"停机条件"：连续亏损、最大回撤、系统异常。
- 永远先模拟 ≥2 周；实盘从总资金 ≤5% 起步。
- 以"系统运行质量"而非"盈亏"评估前 3 个月。
