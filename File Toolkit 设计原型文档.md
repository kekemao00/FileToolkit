# File Toolkit — 设计原型文档

> 版本：v0.1 | 阶段：Windows MVP | 更新：2026-04-07

---

## 一、设计原则

| 原则 | 说明 |
|---|---|
| **简洁优先** | 每个页面只做一件事，减少用户决策成本 |
| **即时反馈** | 所有操作有加载态、成功态、失败态 |
| **拖拽优先** | 文件输入优先支持拖拽，点击选择为辅 |
| **本地安全** | 明确告知用户文件不上传，增强信任感 |
| **渐进披露** | 基础参数默认隐藏，高级选项折叠展开 |

## 五、交互状态规范

### 5.1 文件拖拽区域状态

```
默认态   虚线边框，灰色背景，提示文字居中
悬停态   实线边框（主色），背景色加深，图标放大
拖入态   实线边框（成功色），背景色高亮
已选择   显示文件名/数量/大小，右上角 × 可移除
错误态   实线边框（错误色），提示"不支持的文件格式"
```

### 5.2 按钮状态

```
默认态   主色填充，白色文字
悬停态   颜色加深 10%
按下态   颜色加深 20%，轻微缩放
禁用态   灰色，不可点击（未选择文件时）
加载态   显示 spinner，文字变为"处理中..."
```

### 5.3 进度条规范

```
确定进度   线性进度条，显示百分比 + 当前步骤描述
不确定进度 循环动画进度条（如 OCR 等待 API 返回）
完成       进度条变绿，显示 ✅ 完成
失败       进度条变红，显示 ❌ 失败原因
```

### 5.4 通知/提示规范

```
成功   SnackBar 底部弹出，绿色，3秒自动消失
警告   SnackBar 底部弹出，橙色，5秒，带[知道了]
错误   Dialog 弹窗，红色，显示错误详情，需手动关闭
信息   SnackBar 底部弹出，蓝色，3秒自动消失
```
